# chrono Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the `ia` CLI into `chrono`, with the "painel B" look (header box, wait spinner, marked and formatted answers, stats line) built on `rich`.

**Architecture:** One file, `chrono.py` (renamed from `ia.py`), keeps the current flow (config → `Conversa` → Ollama `/api/chat` streaming). Screen output moves behind an `Exibidor` interface with two implementations: `ExibidorSimples` (output not going to a terminal: raw text only) and `ExibidorRico` (rich: spinner, bar, markdown per block, stats). Pure formatting helpers produce the header rows and the stats line, so they can be tested without a terminal.

**Tech Stack:** system Python 3.9.6 (`/usr/bin/python3`), `rich` (pip `--user`), stdlib `unittest` and a fake Ollama HTTP server for tests.

**Spec:** `docs/2026-11-02-chrono-design.md`

## Global Constraints

- Python 3.9: no `match`, no `X | Y` outside annotations; add `from __future__ import annotations` if using `dict | None` hints.
- Only new dependency: `rich`, installed with `/usr/bin/python3 -m pip install --user rich`.
- Name: command `chrono`; data folder `~/.chrono` (config `config.json`, `conversas/`, `digitados`).
- All user-facing text in Brazilian Portuguese; decimals with comma (`2,4 s`).
- Colors: bar `#7F77DD`, label/brand `#AFA9EC`, "você ›" `#5DCAA5`, details `#888780`, spinner `#EF9F27`, header border `#5F5E5A`.
- Output not going to a terminal: only the raw answer text, no ANSI codes, no stats.
- Without `rich` and output going to a terminal: print `O chrono precisa da biblioteca rich. Instale com: pip3 install --user rich` to stderr, exit 1, no traceback.
- Thinking text is no longer printed; only the spinner `pensando… N s` and `pensou N s` in the stats line.
- The folder is not a git repo: no commit steps.

## Review Focus

1. Answer taller than the screen: every paragraph appears exactly once, no flicker of old text → test in Task 4 (`test_blocos_aparecem_uma_vez`).
2. Ctrl+C before the first word (still on the spinner): spinner stops, `[interrompido]`, chat keeps going → pty test in Task 5.
3. Ollama off or model missing while in the rich UI: the existing Portuguese messages in red, no traceback, chat keeps going → test in Task 5 (`/modelo nao-existe`) and Task 1 (`Ollama fora do ar`).
4. Narrow terminal (40 columns): header and stats wrap without crashing → test in Task 4 (`test_cabecalho_largura_40`).
5. Output redirected (`chrono "x" > arquivo`): file has only the answer, no ANSI codes → test in Task 1.
